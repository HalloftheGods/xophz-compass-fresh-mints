# Xophz Compass Fresh Mints WordPress Plugin

Turnkey lead discovery, license registry audit, skip-tracing, and practice website launcher platform integrated with Questbook CRM and the WP Connectors API.

## Capabilities

* **Standalone Svelte 5 SPA Router:** Deployable at default `/fresh-mints`, custom slugs, or site front page.
* **WP Connectors API Gateway:** Secure Gemini AI cold email/SMS generation and live web search grounding without exposing API keys.
* **Credentials stay on the server:** every key and webhook URL is read through the WordPress Connectors API (Settings > Connectors) and used only by PHP. Nothing secret is stored in the browser, bundled, returned by a REST route or placed in a URL; Gemini and YouTube keys travel in the `x-goog-api-key` header.
* **Social dispatch webhook:** `POST /xophz-freshmints/v1/social/dispatch` relays a dispatched Social Radar reply to the Slack, Discord or Zapier URL held in the `social_dispatch_webhook_url` connector (constant and env var `COMPASS_SOCIAL_DISPATCH_WEBHOOK_URL`). With no URL configured it answers `freshmints_webhook_not_configured` and the app falls back to copy-and-paste.
* **CRM lead webhook:** `POST /xophz-freshmints/v1/crm/webhook` (body `{ event, data }`, administrators only) relays a lead or a list of leads to the Zapier, Make, HubSpot or GoHighLevel URL held in the `crm_webhook_url` connector (constant and env var `COMPASS_CRM_WEBHOOK_URL`). The browser never holds that URL: the earlier `licensify_crm_webhook` localStorage value is deleted when the app loads. With no URL configured it answers `freshmints_crm_webhook_not_configured`; the other errors are `freshmints_crm_webhook_invalid` (400), `freshmints_crm_webhook_unreachable` and `freshmints_crm_webhook_rejected` (502), none of which carry the URL.
* **Reddit through the official Data API:** the Reddit provider of `POST /xophz-freshmints/v1/social/fetch` uses app-only OAuth (`client_credentials`) against `oauth.reddit.com`, with the token cached server-side until shortly before it expires and Reddit's rate-limit headers respected. It needs three connectors, registered only if no other plugin has already: `reddit_client_id` (`REDDIT_CLIENT_ID`), `reddit_client_secret` (`REDDIT_CLIENT_SECRET`) and `reddit_username` (`REDDIT_USERNAME`, named in the required `(by /u/username)` User-Agent). Create the app at https://www.reddit.com/prefs/apps. With any of them missing it answers `failed` / "Reddit is not configured."; there is no public-JSON fallback.
* **Questbook CRM Sync:** 1-Click contact sync into WordPress CPT `questbook_contact` with full provenance tracking.
* **Dev Server Proxy:** Transparent HMR proxying to local Vite dev server on port 8091 during development.

## Reddit data handling

What Social Radar does with Reddit data, as the code stands. The Reddit Data API terms this is written to meet: store minimal fields, keep them for a short window, drop content deleted or removed on Reddit, build no user profiles, no AI training.

* **What is kept.** A lead keeps the post's id, title, permalink, subreddit, created time and score, plus our own output: the matched rule and keyword, intent score, pain-point label, draft reply, status and the time it was evaluated. The post body is read once, to evaluate the post, and is never stored. The author's handle is kept only while the lead is open for a reply (status `radar`); converting or dismissing a lead removes it, and removes it from the draft reply too. Leads live in the browser (`fresh_mints_social_leads` in localStorage); leads saved by an earlier version lose their body text the next time the app loads. The server stores no social post and no Reddit listing: its only Reddit state is the OAuth token and the rate-limit pause. The same rule applies to leads from every platform, not only Reddit.
* **How long.** The window is the setting "Social Radar Retention (days)" under Settings > Fresh Mints (option `xophz_compass_freshmints_social_retention_days`, default 30, allowed 1 to 90). The app reads it from `GET /xophz-freshmints/v1/social/retention` and deletes every lead older than it, counted from when the lead was taken in, when the app loads and after each scan. If the server cannot be read it uses the last value it read, else 30.
* **Deleted or removed posts.** `POST /xophz-freshmints/v1/social/live-check` takes `{ ids }`, up to 100 Reddit post ids (bare or `t3_`), and asks Reddit `GET /api/info?id=t3_...` once, through the same app-only OAuth transport as the search, so Reddit's rate-limit headers and any pause are honored. A post is not live when `removed_by_category` is set, the author is `[deleted]`, the body is `[removed]` or `[deleted]`, or Reddit does not return it. The answer is `{ status: 'ok', live, gone: [{ id, reason }], invalid }`. The app runs the check when it loads and after each scan and drops the leads that are gone, and it runs it again right before a reply is dispatched: a reply for a post that is not confirmed live is refused, and a gone post drops the lead.
* **No guessing.** If Reddit is not configured, the route answers `code: 'not_configured'`; if Reddit asked for a pause, `code: 'rate_limited'` with `retryAfterSeconds`; if Reddit cannot be reached, `code: 'unreachable'`. It then returns no verdicts. The app keeps the leads, says it could not re-check them and why, and refuses to dispatch until it can confirm the post.
* **No profiles, no AI.** Nothing groups or looks up leads by author, and a Reddit lead that is converted to a CRM lead is named for the thread (`Reddit thread: <title>`), not the person. No Reddit text or handle is sent to an AI model, and nothing here trains or fine-tunes one: the intent score is a fixed pattern match. The CRM actions that call Gemini (skip trace, pitch generator) send the CRM lead's name, which for a converted Reddit lead is the thread title.
* **Access.** Both routes are administrators only (`manage_options`), through the same permission callback as `POST /xophz-freshmints/v1/social/fetch`. A human sends every reply.
