# Changelog

All notable changes to the Xophz Compass Fresh Mints plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [2026-10-12]

### Changed
- **Reddit search moved onto Reddit's official Data API ([class-freshmints-social-reddit-api.php](file:///home/xopher/www/x/Xophz-COMPASS/wp-content/plugins/xophz-compass-fresh-mints/includes/social/providers/class-freshmints-social-reddit-api.php), [class-freshmints-social-provider-reddit.php](file:///home/xopher/www/x/Xophz-COMPASS/wp-content/plugins/xophz-compass-fresh-mints/includes/social/providers/class-freshmints-social-provider-reddit.php), #6028)**: The Reddit provider no longer reads the public `www.reddit.com` search JSON. It uses app-only OAuth (`grant_type=client_credentials`, HTTP Basic with the app's id and secret) against `https://www.reddit.com/api/v1/access_token`, caches the bearer token in a transient until two minutes before it expires (and drops it and renews once on a 401), and searches `https://oauth.reddit.com/r/<subs>/search` with a `wordpress:TopicRadar:v<version> (by /u/<username>)` User-Agent. The `X-Ratelimit-*` headers and any 429 `Retry-After` pause the provider (capped at ten minutes), so a scan never retries into a limit. The app is shared with YouMeOS Topic Radar, so the three connectors register only when nobody else has: `reddit_client_id` (`REDDIT_CLIENT_ID`), `reddit_client_secret` (`REDDIT_CLIENT_SECRET`) and `reddit_username` (`REDDIT_USERNAME`, the account named in the User-Agent), all under Settings > Connectors with credentials at `https://www.reddit.com/prefs/apps`. With any of them missing the provider answers `failed` / "Reddit is not configured." and makes no request; there is no public-JSON fallback. The secret and the token are never put in a response or a reason.
- **Reddit enable option removed**: `xophz_compass_freshmints_social_reddit_enabled` is no longer read. Setting the connectors is what turns Reddit on. A leftover value in `wp_options` is inert and can be deleted. Owner action before real use: register a Reddit "script" or web app and apply for Data API access for commercial use.
- **Texas producer registry returns only first-time licensees and pages past the old 200-row cap ([class-freshmints-registry-producers.php](file:///home/xopher/www/x/Xophz-COMPASS/wp-content/plugins/xophz-compass-fresh-mints/includes/registry/class-freshmints-registry-producers.php), [class-freshmints-registry-producer-rows.php](file:///home/xopher/www/x/Xophz-COMPASS/wp-content/plugins/xophz-compass-fresh-mints/includes/registry/class-freshmints-registry-producer-rows.php), #6022)**: `Freshmints_Registry_Producers::fetch()` used to return any life licence issued in the window, which includes producers who have held a Texas licence for years and just added a life line. With a window it now returns only people whose earliest Texas licence of any kind (any address state, any licence type, matched on NPN with `min(license_issue_date)` grouped by `npn`) falls inside the window, one lead per NPN, built from that person's earliest life row in the window. Window rows are read 1,000 at a time (hard cap 20,000 rows) and the first-issue check runs in chunks of 150 NPNs, newest first, so `$limit` still means "most leads returned" and a small limit stops after a page or two. The lead for a person is the same whatever the limit. Each request has a 15 second timeout and one retry on a transport error, 429 or 5xx; one `fetch()` stops after 45 seconds (filter `freshmints_registry_producers_time_budget`); a person whose first-issue check could not run is left out, never passed unchecked. New optional fourth argument `bool $first_license_only = true` (pass `false` for the old any-life-licence behavior); with no window (`all`) every licence age is wanted and the flag has no effect. New `Freshmints_Registry_Producers::last_stats()` reports requests, rows read, rows without an NPN (skipped in first-license mode), people checked and kept, and `complete` (false when a request failed or the cap or time budget stopped the run). Dataset access moved to the new `Freshmints_Registry_Producer_Rows` class. `MAX_FETCH_ROWS` is gone. The `/registry/fetch-live` route still clamps `limit` to 100.

## [2026-10-10]

### Security
- **CRM webhook URL moved onto a Connector ([class-freshmints-crm-webhook-rest.php](file:///home/xopher/www/x/Xophz-COMPASS/wp-content/plugins/xophz-compass-fresh-mints/includes/crm/class-freshmints-crm-webhook-rest.php), #5961)**: The CRM webhook URL (a bearer credential) was stored in browser `localStorage` (`licensify_crm_webhook`) and POSTed to from the page. It is now the `crm_webhook_url` connector (Settings > Connectors; constant and env var `COMPASS_CRM_WEBHOOK_URL`), and the new administrator-only route `POST /xophz-freshmints/v1/crm/webhook` validates the event and leads, then makes the one outbound POST. Errors carry a code and the webhook's HTTP status, never the URL. The client deletes any `licensify_crm_webhook` value it finds on load. Anyone who pasted a CRM webhook URL into the old Settings field should treat it as exposed and rotate it.
